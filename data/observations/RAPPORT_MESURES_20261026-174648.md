## C2 — Agent de dépannage

Question neutre identique pour chaque cas ; la cause n'est jamais donnée. Note 1 = cause exacte, 0,5 = partielle, 0 = fausse.

- **mots-clés** : la réponse contient les termes de la cause (une réponse qui énumère toutes les causes possibles peut les atteindre) ;
- **stricte** : en plus, un détail qu'on ne peut connaître qu'en observant le cluster (tag 9.99, port 8081, limite 48Mi, sélecteur « backnd »…) ; une réponse qui refuse de conclure (« je ne peux pas me prononcer… ») est une **abstention** et vaut 0. Note manuelle prioritaire si saisie (campaign_agent_manual.csv).

Banc **v1** (invalidé) : noms parlants (agent-oom…) et cause écrite en annotation, lue par l'agent dans 4 réponses sur 10. Banc **v2** : noms neutres (svc-01…), aucune annotation.
